# 꿈별이의 룸메이트 방 구경 (모바일 프로토타입)

## 실행
- `index.html`을 브라우저에서 열면 실행됩니다.
- GitHub Pages에 적용할 경우, 이 폴더의 **내용물 전체**를 저장소에 업로드하세요. `index.html`과 `assets` 폴더가 같은 위치에 있어야 합니다.

## 기능
- 모바일 우선 레이아웃
- 룸메이트 유형이 적힌 방문 3개
- 문 선택 시 해당 방으로 전환
- 방별 배경과 꿈별이 이미지
- 꿈별이 말풍선 변경 버튼
- 방 안 아이템 터치 반응
- 방문 화면으로 돌아가기 / 다음 방 이동

## 파일 구성
- `index.html`: 화면과 상호작용
- `assets/rooms/`: 방 배경 3종
- `assets/mascots/`: 꿈별이 3종 투명 PNG

참고: 이 프로토타입은 새 프로젝트로 테스트하도록 구성되어 있으며 기존 사이트 파일을 덮어쓰지 않습니다.
